## 4. Show HN draft

Title:
```
Show HN: A deterministic policy firewall for AI agent tool calls
```

Body:
```
I got tired of "AI agent guardrails" meaning either an LLM call that
scores risk (probabilistic, another API dependency) or an MCP tool the
agent can just... not call. Guardrail is neither: YAML rules
(blocklists, regex on arguments, numeric limits, rate limits) evaluated
deterministically, plus a Python decorator, @enforce(), that wraps the
actual function doing the side effect — so a block happens whether or
not the model "chooses" to check first.

It also ships an MCP server for the advisory case, and a CLI. No LLM
calls anywhere in the decision path, no network dependency, no API key.

It's a small, honest project — 46 tests, MIT license, README says
plainly what's missing (single-process SQLite, no PII redaction in the
audit log yet, auth-less confirmation UI). Feedback and "here's how you
got past my rule" issues very welcome.

https://github.com/rudimentall1/agent-guardrail
```

Post once, don't resubmit if it doesn't land the first time — HN
penalizes repeat submissions of the same URL.
