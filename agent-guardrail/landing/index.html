why this, not risk scoring

Every decision points at a rule you can read.

Most "AI agent security" tools compute a statistical risk score from data nobody can verify at build time. Guardrail doesn't — it only makes claims it can back up.

✕ risk-scoring tools

  • A number (e.g. "risk: 62") with no way to audit how it was reached
  • Often backed by mock or placeholder data pretending to be live
  • Needs paid data feeds before it means anything real
  • Hard to explain a false positive to the person it blocked

✓ guardrail

  • A rule name and a message — read it in `policies/default.yaml` yourself
  • Every check is a blocklist entry, regex, cap, or rate limit — nothing simulated
  • Works fully offline, no API keys, no data subscription
  • "Blocked because matched" — always

install

Running in under a minute.

terminal
# clone & install
git clone https://github.com/<you>/agent-guardrail
cd agent-guardrail
pip install -r requirements.txt

# try it — this will BLOCK
python3 cli.py check --agent trading-agent-001 --tool wallet.transfer \
  --args '{"amount": 9999, "to": "0xabc"}'
